# Subject-reset boundary
- Per-subject reset reads the server-owned source/version (`exam_subject_reset_context`), verifies displayed learner/result identity, then requests a dedicated append-only admin authorization with readback; the learner alone starts the new tentative (owner-only deferred start). Open copies and unproven old/V2 links are refused, never replaced; no global or owner-start fallback; why: admin must never start timers, alter other subjects or rewrite grades. Server changes must pass `src/test/admin_subject_reset_sql_contract.py` and `src/test/admin_subject_reset_live_contract.py` (live triggers on a disposable cluster).
